The app code in its own file, drills.app.js (Build CW)

Measured: three quarters of the time to the first screen is the browser
reading the 8 MB of code that sat inside drills.html. precompile.js now
writes it as its own file next to the page, loaded with a version in
the address. On a copy with a slower CPU the first screen comes about a
third sooner, and a returning student's another third, because the
browser keeps the file and its compiled code. Nothing a child sees
changes. Commit and push drills.html and drills.app.js together.
